# Referências

Use este arquivo para registrar fontes consultadas pelo grupo.

## Critérios para aceitar uma fonte

- A fonte deve ser confiável e verificável.
- Artigos acadêmicos, livros, relatórios institucionais e documentação oficial devem ter prioridade.
- Conteúdos gerados por IA devem ser revisados e não devem ser tratados como fonte primária.

## Modelo

```text
Título:
Autor/Instituição:
Ano:
Link:
Resumo:
Como será usada no trabalho:
```
